# 등교 알리미

2026-2학기 시간표와 하루 루틴으로 만든 알림 앱.

- **웹앱** (`index.html`): 등교 출발까지, 다음 할 일까지 남은 시간. 폰 크롬에서 "홈 화면에 추가"로 설치. 워치처럼 좁은 화면에서는 큰 숫자만 보입니다.
- **알림** (`timetable.ics`): 삼성 캘린더에 넣으면 폰과 갤럭시 워치에서 울립니다.
  - 학교 가는 날: 헬스 1시간 30분 전 출발 알림
  - 수업: 10분 전
  - 과제·그림·독서·게임: 시작할 때, 자정에 게임 끝 알림

## 시간 바꾸기

1. `make_ics.py`의 `EVENTS`, `index.html`의 `ITEMS`를 같이 고칩니다.
2. `python make_ics.py`로 `timetable.ics`를 다시 만듭니다.
3. 올린 뒤 삼성 캘린더에서 예전 일정을 지우고 새 파일을 넣습니다.
